# Requirements

## Functional
1. **Smooth Scrolling**: Lenis at layout level, synced with Framer Motion scroll animations
2. **All 6 Projects Displayed**: Horizontal scroll with 3D parallax cards
3. **Skills Section Transitions**: Multi-directional colorful transitions (left, right, top, bottom, center morph)
4. **Hero Section**: Code-typing effect, 3D geometric background, scroll parallax
5. **About Section**: 3D depth layers, scroll reveals, terminal-style content
6. **Projects Section**: Horizontal scroll, 3D card tilt, hover expansions
7. **Journey Section**: Timeline with 3D node connections
8. **Contact Section**: Form with 3D input focus states

## Non-Functional
1. **Performance**: 60fps desktop, 30fps mobile; <16ms frame time
2. **Responsive**: 3D on desktop, graceful 2D fallback on mobile
3. **Reduced Motion**: Full static fallback respecting prefers-reduced-motion
4. **Accessibility**: Semantic HTML, focus states, WCAG AA contrast
5. **Premium Feel**: Custom shaders, HSL gradients, glassmorphism, depth layers
6. **No Astronaut/Space Theme**: Pure CSE/engineering aesthetic
