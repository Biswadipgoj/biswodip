## How I engineer software

```text
01  Understand   Requirements → workflows → constraints
02  Model        Data → domain → permissions → contracts
03  Build        Interface → application logic → APIs → database
04  Verify       Tests → edge cases → workflow validation
05  Ship         CI → deployment → production iteration
```

I start with the business workflow, choose a data model that reflects real relationships, validate at system boundaries, and make important behaviour easy to verify.
