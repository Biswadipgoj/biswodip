# Visual Design & System Style Directive

## 1. Non-Negotiable Background Constraint
- **NEVER use dark mode, black, charcoal, or dark obsidian** (`#000000`, `#080a0f`, `#111827`, `#0d1117`).
- **NEVER use flat pure white** (`#ffffff`).
- **ALWAYS use a vibrant, luminous Multicolor Gradient Mesh**:
  - Interlocking animated ambient gradients: Royal Violet, Electric Azure, Radiant Amethyst, Vibrant Cyan, Sunset Coral, Emerald Glow.
  - Saturated, luminous, high-energy spatial atmosphere.

## 2. Spatial Glassmorphism ("Glassophorium") UI
- All cards, panels, navbars, and windows MUST use **Frosted Spatial Glass**:
  - `backdrop-blur-2xl` or `backdrop-blur-3xl`
  - Translucent glass backgrounds: `bg-white/[0.08]` to `bg-white/[0.14]` (or colorful translucent tints)
  - Refractive hairline glass borders: `border border-white/[0.22]` with specular gradient highlights
  - Deep luminous spatial drop-shadows: `shadow-[0_20px_50px_rgba(0,0,0,0.25)]` paired with colorful ambient under-glows
  - VisionOS/macOS spatial UI depth with floating layers, 3D perspective tilts, and elevation.

## 3. High-Energy Fluid Animations & Motion
- **Plenty of motion and life**:
  - 3D interactive spatial tilt on hover (`transform-style: preserve-3d`)
  - Floating animated ambient orbs drifting across the canvas
  - 120 FPS Three.js 3D computer workstation
  - Live animated interactive simulators (WebSocket telemetry, Base62 compressor, Event Loop ticks, B-Tree index traversal)
  - Animated glowing pulse indicators and micro-interactions
  - Never make the site look static, dim, or dull.
